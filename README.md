# Study Canvas

iPad Safariで、週間目標を教科別テキストからカード化し、今日の手書きキャンバスへドラッグして配置する受験勉強管理Webアプリです。

正式版はAI・OCR・学習時間集計を使用しません。2026年7月28日時点のOCR版は、観賞用の`/ocr-experiment/`として別保存します。

## 主な機能

- 教科別テキストを改行ごとに週間カード化
- 週間カードを今日の手書きキャンバスへドラッグ配置
- 日付ごとのカード位置・完了状態の保存
- 青・赤・黒の手書き
- ペンの太さ変更
- ストローク単位の消しゴム
- 取り消し・やり直し
- Safari内への自動保存
- 再読み込み後の復元
- 自由ノート
- 全データのバックアップと復元
- iPad縦向き・横向きに対応

## 確認方法

追加のライブラリは不要です。ローカルでは静的Webサーバーで開いてください。

```bash
python3 -m http.server 8000
```

テストと静的検査:

```bash
npm test
npm run build
```
